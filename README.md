# PIZZA-ORDERING-SYSTEM

#Name
Jenlyn A. Paler

The Pizza Ordering System is a user-friendly application that allows customers to order pizza easily. 
Users can select a pizza flavor, choose a size, add extra toppings, and enter the desired quantity. The system automatically calculates the total cost, displays an order summary, and asks for confirmation before placing the order. It also includes a reset button to clear all selections and start a new order.
